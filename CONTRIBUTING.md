# Contributing to ReVibe

## Workflow

1. Create a feature branch from `main`.
2. Make a focused change.
3. Test the change before submitting it.
4. Commit the change with a clear message.
5. Open a pull request with a description.
6. Merge the pull request into `main` after checks pass.

## Commit Messages

Use short messages that clearly describe the change, for example:

- `Add documentation`
- `Update CI configuration`
- `Fix test script`

## Pull Requests

Each pull request should explain:
- What was changed.
- Why the change was made.
- How the change was tested.
